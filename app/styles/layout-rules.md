# 自适应规则

界面在 1024–1920 宽、540–900 高的窗口里都要好用。CSS 实现见 `layout.css`（网格和文字规则）与 `shell.css`（侧栏和页面框架）。

## 页面
- 页面内容最大宽度 1440px，居中；左右留白用 `--inline-pad`（窄于 1440 时等于 `--gutter`：28px，图标栏 20px，顶部菜单 14px）。滚动条始终贴着窗口边。
- `.page` 是名为 `page` 的容器。页面内部的版式变化用 `@container page (...)`，不看视口宽度：同样 900px 宽的窗口，开着侧栏和收起侧栏时内容宽度不同。
- 只有应用框架（侧栏）和会盖住页面的检查器按视口断点变化。

## 侧栏
- 顶部（品牌 + 主导航）和底部（应用更新提示 + 设置 + 扫描状态）固定，中间的 Agent 列表是唯一滚动的区域，上下边缘淡出。
- 高度 < 600：Agent 列表收进“Agent”展开按钮。高度 ≤ 700 / ≤ 560 时导航行距逐级收紧。
- 宽度 < 900：收起成 60px 图标栏，名称放进提示（title），数量变成小圆点。
- 宽度 < 640：变成顶部菜单栏。

## 卡片网格
一律 `repeat(auto-fill, minmax(min(W, 100%), 1fr))`，W 按卡片类型统一：

| 类型 | W | 用在 |
| --- | --- | --- |
| `--w-tile` | 180px | 连接器 / MCP 小块、Agent 勾选、汇总小卡、总量条 |
| `--w-option` | 220px | 单选卡片 |
| `--w-pick` | 250px | 常用 Agent 选择卡 |
| `--w-card` | 260px | 插件、专家、技能库 Agent、修复卡 |
| `--w-agent` | 300px | 首页 Agent 卡 |
| `--w-panel` | 320px | 成对的面板（我做的专家、使用数据两栏） |
| `--w-wide` | 380px | 数据页带图表的 Agent 卡 |

## 卡片内文字
- 标题单行，超出省略（`.clamp-1`）；说明最多两行（`.clamp-2`）。
- 数字不换行（`.num`、`.metric b`、汇总数字都带 `white-space: nowrap`）。
- 一行里有多段信息时，拆成多行各自省略，不让一句话在中间折断（例如常用 Agent 卡：“近 30 天 408 个会话 · 50 天在用”和“229 个技能”各占一行）。
- 勾选框、按钮等可点区域固定尺寸，切换状态不推动文字。

## 高度
- 页面头部在高度 ≤ 640 时收紧内边距；吸顶条（专家 Tab、设置导航）和弹窗底部操作栏在矮窗口里依然可见。
- 弹窗最大高度 `100dvh - 48px`，标题和底部操作栏固定，中间内容滚动。

## 检查
每次改版式，在 1024、1280、1440、1920 宽和 700、900 高下看一遍所有页面，再看 540 高（常见的小窗口）。
