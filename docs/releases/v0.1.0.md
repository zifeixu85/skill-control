# Skill Control v0.1.0

这是 Skill Control 的第一个公开最小可用版本。它把 Codex、Claude Code、
WorkBuddy 和其他兼容 `SKILL.md` 的本地技能目录放进一个可视化工作台。

This is the first public minimum viable release of Skill Control, a local-first
desktop manager for Skills shared across Codex, Claude Code, WorkBuddy, and
other `SKILL.md`-compatible tools.

## 主要功能 / Highlights

- 自动发现本机 Agent Skill 目录，也可以添加自定义工具和目录；
- 中文名称或介绍存在时优先显示中文；
- 浏览 Skill 文件树，文件夹默认折叠并打开 `SKILL.md`；
- 已安装 Skill 和导入包均支持 Markdown 排版预览与原始内容切换；
- 在 macOS、Windows 和 Linux 文件管理器中定位 Skill 目录；
- 导入、预览、安装和导出 `.skill` 技能包；
- 比较跨 Agent 安装覆盖与内容指纹；
- 复制或软链接同步，执行前展示计划；
- 替换前自动备份，写入必须经过明确确认；
- 本地优先，无遥测，不上传 Skill 内容。

## 下载 / Downloads

| 平台 | 架构 | 产物 |
| --- | --- | --- |
| macOS | Apple Silicon、Intel | DMG、ZIP |
| Windows | x64 | NSIS 安装程序、portable EXE |
| Linux | x64 | AppImage、DEB |

所有文件名都包含版本、平台和架构。`SHA256SUMS.txt` 提供发布产物的 SHA-256
校验值。

Every filename includes its version, platform, and architecture. Verify
downloads with the included `SHA256SUMS.txt`.

Apple Silicon Mac 应下载文件名含 `mac-arm64` 的版本；Intel Mac 下载
`mac-x64`。不要在 Apple Silicon 上误选 x64 包，否则 macOS 可能显示 Intel
应用兼容性提醒。

On Apple Silicon, choose the artifact containing `mac-arm64`; on an Intel Mac,
choose `mac-x64`. Selecting the x64 build on Apple Silicon may trigger an Intel
application compatibility notice.

## 安装提醒 / Installation notes

本版本的桌面安装包由公开 GitHub Actions 构建，但尚未使用商业代码签名证书：

- macOS 可能要求在“系统设置 → 隐私与安全性”中确认打开；
- Windows SmartScreen 可能显示“未知发布者”；
- Linux AppImage 需要先赋予执行权限。

The desktop artifacts are built by public GitHub Actions but are not yet signed
or notarized with commercial platform certificates. Operating systems may show
an unknown-publisher warning.

## 已知限制 / Known limitations

- 暂不提供应用内自动更新，请从 Releases 下载新版本；
- 暂无备份浏览与一键恢复界面，备份保存在
  `~/.agent-skill-manager/backups/`；
- 内置 Agent 目录规则可能随上游工具变化，必要时可以使用自定义目录；
- Windows 软链接可能要求启用“开发人员模式”或额外权限；
- 软链接模式会让多个工具共享同一份实际内容，请只在理解该行为时使用。
- 卸载桌面应用不会自动删除 `~/.agent-skill-manager/` 中的配置、导入预览、
  操作历史和备份；确认不再需要后可手动删除。

## 从源码运行 / Run from source

需要 Node.js 22.13.0 或更高版本：

```bash
npm ci
npm run dev
```

完整说明见仓库中的 `README.md`、`README_EN.md` 和 `CHANGELOG.md`。
