# Skill Control v0.3.0

Skill Control 是一个本地优先的 AI Agent 管理工具：在一处查看和整理 Codex、Claude Code、WorkBuddy、Hermes、OpenClaw 等 Agent 的技能、插件、MCP、命令行工具和用量。这一版让技能库真正做到“装一次，各 Agent 都能用”，并按新用户的第一次使用体验改了下载、首次打开、隐私说明和联网控制。

[English below](#english)

## 主要变化

- **技能库优先**：技能只在 `~/.agents/skills` 放一份，各 Agent 按自己的方式接入：会自动读取、逐个建链接、加一次额外目录，或者复制一份。新放进库的技能会自动接入常用 Agent，每次都能撤销；库里原有的缺口用“补齐接入”一次处理，确认后才执行。安装方式默认改为统一技能库，从旧版本升级的也会切换过来；想继续各装一份，可以在“设置 → 安装方式”里改回。
- **命令行工具和 skill-control 技能**：在“设置 → Agent 集成”里安装 `skill-control` 命令（macOS、Linux）和随附的 `skill-control` 技能。在 Agent 里装技能时也会走技能库：先问装给哪些 Agent、做一次安全检查，再放进库并接入，可以撤销。
- **第一次使用更顺**：引导分两步，先说明会读什么、会不会联网，再选常用 Agent；按 Agent 自己的文件判断是否安装，没装的不再出现；体检不再对没装的 Agent 报问题；导入技能支持 `.zip` 和文件夹；同名技能内容不同时，可以查看差异，或用较新的一份更新。
- **隐私与联网**：新增“自动检查更新”开关，新安装在你看过说明之前不会自动联网；版本检查走系统代理；新 Agent 发现每天最多一次，不再打开通讯录、邮件等受保护的目录；[隐私说明](https://github.com/zifeixu85/skill-control/blob/main/PRIVACY.md)按实际读取的位置重写。
- **签名与应用内更新**：macOS 版改用一张固定的自签名证书签名；应用内更新会核对新版本出自同一张证书；macOS 阻止替换时，会告诉你到“App管理”里允许，或打开下载页手动更新。
- **可访问性**：浅色主题的灰色文字加深；菜单补上放大、缩小、实际大小、关闭窗口（⌘W）、设置…（⌘,）和帮助。

## 第一次打开

- **macOS**：把应用拖进“应用程序”后双击打开。提示 未打开“Skill Control” 时点“完成”，再到“系统设置 → 隐私与安全性”底部点“仍要打开”，并用密码或触控 ID 确认。这个按钮只在被拦后大约一小时内显示，找不到就先再双击一次应用。详细步骤和签名核对方法见 [README](https://github.com/zifeixu85/skill-control#首次打开macos)。
- **Windows**：SmartScreen 提示“Windows 已保护你的电脑”时，点“更多信息 → 仍要运行”。
- **Linux**：AppImage 需要先赋予执行权限（`chmod +x`），并装好 libfuse2。

## 隐私

没有遥测，不上传技能、对话、密钥或路径。会读取会话记录文件来统计次数和 Token，只保存数字；密钥的值不显示、不保存，只在本机保存一个加盐指纹。检查更新会访问 GitHub、npm 和各 Agent 应用自己的更新地址，可以在“设置 → 数据与隐私”里关闭。

## 已知限制

- 界面目前只有简体中文，英文界面计划在下一版提供。
- macOS 版没有经过 Apple 公证，第一次打开需要在“隐私与安全性”里放行。
- Windows 和 Linux 版测试较少。
- 命令行工具 `skill-control` 目前只支持 macOS 和 Linux。

完整变化见 [CHANGELOG](https://github.com/zifeixu85/skill-control/blob/main/CHANGELOG.md)。

## English

Skill Control is a local-first manager for AI coding agents: see and organize the skills, plugins, MCP servers, command-line tools and usage of Codex, Claude Code, WorkBuddy, Hermes, OpenClaw and more in one place. This release makes the skill library work as promised (install once, use in every agent) and reworks download, first launch, the privacy notice and network controls for new users.

> **The app's interface is currently Simplified Chinese only; an English interface is planned for the next release.**

**What's new**

- **Library first**: each skill is stored once in `~/.agents/skills`, and each agent reaches it its own way: natively, through a link per skill, through an extra directory, or as a copy. New library skills are connected to your primary agents automatically, and every run can be undone; gaps that already existed are filled with a catch-up plan you confirm. The shared library is now the default install mode, also for upgraded installs; switch back to a copy per agent in 设置 → 安装方式 (Settings → Install mode).
- **Command line and the skill-control skill**: install the `skill-control` command (macOS, Linux) and the bundled `skill-control` skill from 设置 → Agent 集成. Skills installed from inside an agent then go through the library too: it asks which agents should get the skill, runs a safety review, then adds and connects it, with undo.
- **A smoother first start**: two-step onboarding (what it reads and whether it goes online, then your primary agents); agents are detected from their own files, so agents you don't have no longer appear; health checks skip agents that are not installed; import accepts `.zip` and folders; differing copies of a skill can be compared, or the older one updated from the newer one.
- **Privacy and network**: a new automatic update checks switch, and a new install does not go online by itself until you have seen the notice; version checks use the system proxy; new-agent discovery runs at most daily and no longer opens protected folders such as Contacts or Mail; the [privacy notice](https://github.com/zifeixu85/skill-control/blob/main/PRIVACY.md#english) is rewritten from what the code actually reads.
- **Signing and in-app updates**: the macOS app is signed with one fixed self-signed certificate; in-app updates check that a new version comes from the same certificate; when macOS blocks the replacement, the app explains how to allow it under App Management or opens the download page.
- **Accessibility**: darker grey text in the light theme; the menu adds zoom in, zoom out, actual size, close window (⌘W), Settings… (⌘,) and Help.

| Mac with Intel | [Skill-Control-mac-x64.dmg](https://github.com/zifeixu85/skill-control/releases/latest/download/Skill-Control-mac-x64.dmg) |

| Linux (x64) | [Skill-Control-linux-x86_64.AppImage](https://github.com/zifeixu85/skill-control/releases/latest/download/Skill-Control-linux-x86_64.AppImage), or the `.deb` on Debian / Ubuntu |

The `.zip`, `latest*.yml` and `.blockmap` files are for in-app updates; you don't need them. `SHA256SUMS.txt` lists checksums for every file.

**First launch**: on macOS, click Done when it says "Skill Control" Not Opened, then click Open Anyway at the bottom of System Settings → Privacy & Security and confirm with your password or Touch ID. The button only shows for about an hour after the app was blocked; if it's missing, double-click the app again first. Details and how to check the signature are in the [README](https://github.com/zifeixu85/skill-control/blob/main/README_EN.md#first-launch-on-macos). On Windows, choose More info → Run anyway in SmartScreen. On Linux, `chmod +x` the AppImage and install libfuse2.

**Privacy**: no telemetry; skills, conversations, secrets and paths are never uploaded. Session files are read to count sessions and tokens, and only the numbers are kept; secret values are never shown or stored, only a salted fingerprint on your computer. Update checks contact GitHub, npm and each agent app's own update address, and can be turned off in 设置 → 数据与隐私 (Settings → Data and privacy).

**Known limitations**

- The interface is Simplified Chinese only; an English interface is planned for the next release.
- The macOS app is not notarized by Apple, so the first launch has to be allowed in Privacy & Security.
- The Windows and Linux builds are less tested.
- The `skill-control` command line supports macOS and Linux only.
