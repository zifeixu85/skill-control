# Skill Control v0.2.0

v0.2.0 把 Skill Control 从“技能同步工具”扩展成一个本机 Agent 工作台：围绕你常用的
Agent 看技能、插件、专家、连接器与 MCP、密钥位置、更新、用量和预估费用，发现问题时给出
能直接交给 AI 的修复指令。应用本身也开始支持应用内更新。

[English below](#english)

## 主要变化

### 常用 Agent 与新 Agent

- **常用 Agent**：在设置里选出你主要使用的 Agent（最多 4 个），技能状态只针对它们判断；
  没有选择时，按近 30 天的会话活跃度给出建议。
- **新增支持的 Agent**：Hermes Agent、OpenClaw、QClaw 和办公小浣熊，各自按产品自己的
  技能规则识别（停用、被覆盖、只读等状态都会标出）；LumiClaw、MotiClaw、Clawith 只读显示。
- **发现新 Agent**：检测到之前没见过的 Agent 时在概览和设置里提示，可以加入常用或标为已知；
  还能在用户目录里找出含 `skills/*/SKILL.md` 的未知目录，一键添加为自定义 Agent 或忽略。
- **Agent 页面**：每个 Agent 一页，集中查看指令、记忆、规则等文件（敏感内容脱敏）、
  工具与权限设置，以及它的技能用量。

### 技能与技能库

- **技能**：按常用 Agent 显示是否一致、哪边较新、重复副本和共享目录；技能详情里有
  近 90 天的使用次数。
- **技能库**：统一管理 `~/.agents/skills` 共享技能库，按每个 Agent 自己的读取规则模拟它
  实际能看到哪些技能；收编副本、改为链接、停用、卸载到废纸篓都先出计划，确认后执行，
  并可以从历史撤销。
- **排序**：技能、插件、专家、MCP 和技能库列表都可以按最近使用、最新安装、最常用或名称排序，
  每个列表各自记住选择。

### 更新

- **技能与插件更新**：识别每个技能和插件的来源（skills CLI、Claude / Codex 插件、
  WorkBuddy、SkillHub、ClawHub、git 等），检查上游是否有新版本；本地改过的内容需要你选择
  保留还是覆盖，更新前自动备份。
- **Agent 软件版本**：每天检查一次各 Agent 有没有新版本，只读取官方来源。
  有官方命令的命令行工具可以“一键更新”：先显示要执行的命令和影响，确认后执行并显示新版本。
- **应用内更新**：见下文“应用更新”。

### 数据与预估费用

- **数据**：汇总 Claude Code、Codex、WorkBuddy、Hermes、OpenClaw、QClaw、办公小浣熊的
  token、会话、技能调用和项目，支持今天、近 7 天、近 30 天、近 90 天和所有时间；每个数字都
  标明是精确、推算还是产品自报。
- **预估费用**：按各厂商官方 API 价格估算，包括长上下文、缓存读写和错峰价；
  订阅内的用量也按 API 等价估算，不等于实际支出。
- **模型价格表**：列出所有已定价的模型、来源和核对日期，价格可能过期时会提示。

### 体检与 AI 指令

- **体检**：检查失效链接、缺失或无效的 `SKILL.md`、过大的技能、不一致的副本、
  缺少的命令与环境变量、配置里的明文密钥、插件状态和技能库问题。
- **AI 指令**：每个问题都可以“复制 AI 指令”交给你自己的 AI 处理（只复制，不改任何东西），
  能安全自动修复的给出“预览修复”：先列出将改动的文件，确认后执行，可以撤销。

### 专家、插件、连接器与密钥

- **专家与 Agent**：WorkBuddy 的“我的专家”和市场专家、专家团成员，Hermes Profile，
  OpenClaw Agent，办公小浣熊的专家与团队，按产品分组查看。
- **插件**：Codex、Claude Code、WorkBuddy、Hermes、OpenClaw 与 QClaw 的插件，含启用状态、
  版本和组件。
- **连接器与 MCP**：跨 Codex、Claude Code、Cursor、Gemini 等的 MCP 服务清单，配置只读、
  密钥打码。
- **密钥**：列出哪些服务的密钥存在哪里、谁在用、最近有没有变化。只显示名称和位置，
  从不读取或显示密钥的值。

### 历史、恢复与卸载

- 同步、导入、更新、技能库和修复都有操作记录，可以从历史恢复；从某个 Agent 卸载技能会
  先移到 Skill Control 的废纸篓，可以还原。

### 设置与关于

- 设置页增加二级导航：常用 Agent、安装方式、外观、数据与隐私、版本检查、关于。
- “关于”里有版本、仓库、许可证、问题反馈和“检查应用更新”。

## 应用更新

从 v0.2.0 开始，Skill Control 会检查 GitHub Releases 上的新版本：启动后（距上次检查超过
24 小时时）和之后每天一次，也可以在“设置 → 关于”里手动检查。有新版本时侧栏底部会出现
提示。

- **macOS**：下载与本机架构对应的 zip，校验 sha512，确认新应用的标识和版本后替换当前
  应用，旧版本移到废纸篓（名称带时间），然后自动重启。任何一步失败都会恢复原来的版本。
  如果应用放在不可写的位置（例如直接从 DMG 运行），会改为打开下载页。
- **Windows**：安装版（`setup.exe`）可以应用内下载并安装；安装包没有代码签名，
  SmartScreen 可能提示“未知发布者”。便携版需要手动下载替换。
- **Linux**：AppImage 可以应用内更新；`.deb` 请手动下载新的安装包。
- 应用内更新只提供正式版本（不含预发布版本）。
- 离线模式（`SKILL_MANAGER_UPDATES_OFFLINE=1`）和从源码运行时不检查更新。

## 从 v0.1.0 升级

v0.1.0 没有应用内更新，请下载 v0.2.0 并替换原来的应用。配置、历史和备份保存在
`~/.agent-skill-manager/`，升级后继续使用。新版本第一次启动后会在后台建立用量索引，
会话多时可能需要一两分钟，期间“数据”页显示进度。

## 安装提醒

安装包由公开的 GitHub Actions 构建，但还没有使用商业代码签名证书或公证：

- macOS 首次打开时可能需要在“系统设置 → 隐私与安全性”中确认“仍要打开”；
- Windows SmartScreen 可能显示“未知发布者”；
- Linux AppImage 需要先赋予执行权限。

## 网络与隐私

Skill Control 仍然没有遥测，也不上传技能内容。v0.2.0 会在以下情况访问网络：

- 应用更新检查：`api.github.com` 和 `github.com` 上本项目的 Release；
- Agent 版本检查与技能、插件更新检测：npm registry、GitHub 以及各产品自己的更新源；
- 一键更新命令行工具时，由该工具自己的官方命令联网。

设置环境变量 `SKILL_MANAGER_UPDATES_OFFLINE=1` 会关闭以上所有检查。详见 `PRIVACY.md`。

## 已知限制

- 安装包尚未签名和公证；
- 费用是按官方 API 价格的估算，不是实际账单；
- 内置 Agent 目录规则可能随上游产品变化，必要时可以添加自定义目录；
- Windows 创建软链接可能需要开启“开发人员模式”；
- 卸载应用不会删除 `~/.agent-skill-manager/` 中的配置、历史、备份和用量索引。

## 校验

`SHA256SUMS.txt` 提供全部发布文件的 SHA-256 校验值。完整变化见 `CHANGELOG.md`。

## English

v0.2.0 turns Skill Control from a Skill sync tool into a local workbench for your
Agents: Skills, plugins, experts, connectors and MCP servers, where secrets are
stored, updates, usage and estimated cost, all centered on the Agents you use
most, with fixes you can hand to your own AI. The app can now update itself.

### Highlights

- **Primary Agents**: choose up to four Agents you use most; Skill status is
  judged against them, with suggestions from 30-day session activity.
- **New Agents**: Hermes Agent, OpenClaw, QClaw and Office Raccoon (办公小浣熊),
  each read with its own Skill rules; LumiClaw, MotiClaw and Clawith are shown
  read-only. Newly detected Agents and unknown folders that contain
  `skills/*/SKILL.md` are surfaced so you can add or ignore them.
- **Agent pages**: instruction, memory and rule files (redacted), tools and
  permissions, and per-Agent usage.
- **Skill library**: manage the shared `~/.agents/skills` library, simulate what
  each Agent actually sees, adopt copies, switch to links, disable or uninstall to
  a trash, always from a confirmed plan that can be undone.
- **Sorting**: Skills, plugins, experts, MCP servers and the library sort by
  recently used, newest, most used or name; each list remembers its choice.
- **Updates**: Skill and plugin updates from their real sources with backups;
  daily Agent version checks against official sources; one-click updates for CLI
  tools with an official update command, shown and confirmed before they run.
- **Usage and estimated cost**: tokens, sessions, Skill calls and projects across
  Claude Code, Codex, WorkBuddy, Hermes, OpenClaw, QClaw and Office Raccoon for
  today, 7, 30 and 90 days and all time, estimated at each vendor's official API
  prices (not your actual bill), with a model price table.
- **Health checks and AI prompts**: every finding has a "copy AI prompt" button
  that changes nothing, and safe fixes have a "preview fix" plan you confirm and
  can undo.
- **Experts, plugins, connectors, MCP and secrets**: read-only views with masked
  configuration. The secrets page lists names and locations only and never reads
  or shows secret values.
- **History, restore and trash** for sync, import, update, library and fix
  operations.
- **Settings and About**: section navigation, version, repository, license,
  issues and "check for app updates".

### App updates

Starting with v0.2.0 the app checks GitHub Releases at start (when the last check
is older than 24 hours), then daily, or on demand in Settings → About.

- **macOS**: downloads the zip for your architecture, verifies its sha512, checks
  the new app's bundle id and version, moves the current app to the Trash with a
  timestamped name, puts the new one in place and relaunches. Any failure restores
  the previous version. An app in a read-only location (for example run from the
  DMG) opens the download page instead.
- **Windows**: the installer build updates in place; installers are not signed, so
  SmartScreen may show an unknown-publisher warning. The portable build is updated
  manually.
- **Linux**: the AppImage updates in place; the `.deb` is updated manually.
- Only full releases are offered, never pre-releases. Offline mode
  (`SKILL_MANAGER_UPDATES_OFFLINE=1`) and source runs never check.

### Upgrading from v0.1.0

v0.1.0 has no in-app updater: download v0.2.0 and replace the app. Settings,
history and backups in `~/.agent-skill-manager/` are kept. The usage index is
built in the background the first time; with many sessions this can take a
minute or two.

### Network and privacy

There is still no telemetry and Skill content is never uploaded. v0.2.0 contacts
the network for app update checks (this repository's releases on
`api.github.com` and `github.com`), Agent version checks and Skill / plugin update
detection (npm registry, GitHub and each product's own update source), and when
you run a one-click CLI update. `SKILL_MANAGER_UPDATES_OFFLINE=1` turns all of
them off. See `PRIVACY.md`.

### Known limitations

- Installers are not code-signed or notarized.
- Costs are estimates at official API prices, not invoices.
- Built-in Agent directory rules can change upstream; add custom directories when
  needed.
- Windows symbolic links may require Developer Mode.
- Uninstalling the app keeps `~/.agent-skill-manager/` (configuration, history,
  backups and the usage index).
