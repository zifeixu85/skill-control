# Skill Control v0.2.0

Skill Control 是一个本地优先的 AI Agent 管理工具：在一处查看和管理 Codex、Claude Code、
WorkBuddy、Hermes、OpenClaw 等 Agent 的技能、插件、专家、MCP、命令行工具、用量和预估费用。
所有数据只在本机读取，不上传。

[English below](#english)

## 主要功能

- **常用 Agent**：选出你主要使用的几个 Agent，技能是否一致、哪边较新、哪里有重复副本都按它们判断；新装的 Agent 会自动提示。
- **技能库**：用 `~/.agents/skills` 统一管理共享技能，装一次多个 Agent 都能用；整理、链接、停用、卸载都先预览，可撤销。
- **更新**：检查技能、插件和各 Agent 软件的新版本；有官方命令的命令行工具可以一键更新（可在终端或后台运行）。
- **数据**：今天、近 7 天、近 30 天和所有时间的 Token 用量、缓存命中率和按官方价格估算的费用，可按 Agent、模型、项目查看。
- **体检**：找出失效链接、配置问题、明文密钥等，每个问题都能复制一段指令交给你自己的 AI 处理。
- **专家、插件、连接器与 MCP、命令行工具、密钥**：看清每个 Agent 装了什么、密钥存在哪里（只显示名称和位置，从不读取密钥的值）。
- **应用内更新**：以后的新版本可以在“设置 → 关于”里一键更新。

## 下载哪个版本

| 你的电脑 | 下载这个文件 |
| --- | --- |
| Mac（M1 / M2 / M3 / M4 等 Apple 芯片） | `Skill-Control-0.2.0-mac-arm64.dmg` |
| Mac（Intel 芯片） | `Skill-Control-0.2.0-mac-x64.dmg` |
| Windows | `Skill-Control-0.2.0-win-x64-setup.exe`（安装版，推荐）；免安装可选 `…-portable.exe` |
| Linux | `Skill-Control-0.2.0-linux-x86_64.AppImage`；Debian / Ubuntu 也可以用 `…-linux-amd64.deb` |

- 不确定 Mac 是哪种芯片：点屏幕左上角苹果菜单 → “关于本机”，看“芯片”一行；写着 Apple M 系列就选 `mac-arm64`，写着 Intel 就选 `mac-x64`。
- 列表里的 `.zip`、`latest*.yml`、`.blockmap` 和 `SHA256SUMS.txt` 是应用内更新和校验用的，不需要下载。

## 第一次打开

安装包还没有商业代码签名：

- **macOS**：把应用拖进“应用程序”后打开；如果提示无法验证开发者，到“系统设置 → 隐私与安全性”点“仍要打开”。
- **Windows**：如果 SmartScreen 提示“未知发布者”，点“更多信息 → 仍要运行”。
- **Linux**：AppImage 需要先赋予执行权限（`chmod +x`）。

## 隐私

没有遥测，不上传技能内容和对话。只有检查更新时会访问 GitHub、npm 等官方来源；设置环境变量 `SKILL_MANAGER_UPDATES_OFFLINE=1` 可以全部关闭。

## English

Skill Control is a local-first manager for AI coding agents. In one place you can see and manage the skills, plugins, experts, MCP servers, command-line tools, token usage and estimated cost of Codex, Claude Code, WorkBuddy, Hermes, OpenClaw and more. Everything is read locally and nothing is uploaded.

**Highlights**: primary agents and new-agent detection; a shared skill library at `~/.agents/skills` with previewed, undoable changes; updates for skills, plugins and agent software (one-click CLI updates in your terminal or in the background); usage, cache hit rate and estimated cost by agent, model and project; health checks with copyable AI prompts; a secrets inventory that shows names and locations only; in-app updates for future releases.

**Which file to download**

| Your computer | File |
| --- | --- |
| Mac with Apple silicon (M1–M4) | `Skill-Control-0.2.0-mac-arm64.dmg` |
| Mac with Intel | `Skill-Control-0.2.0-mac-x64.dmg` |
| Windows | `Skill-Control-0.2.0-win-x64-setup.exe` (recommended) or the portable `.exe` |
| Linux | `Skill-Control-0.2.0-linux-x86_64.AppImage`, or the `.deb` on Debian / Ubuntu |

The `.zip`, `latest*.yml`, `.blockmap` and `SHA256SUMS.txt` files are used by in-app updates and checksums; you don't need them.

**First launch**: the installers are not code-signed yet. On macOS, allow the app in System Settings → Privacy & Security; on Windows, choose More info → Run anyway in SmartScreen; on Linux, `chmod +x` the AppImage.

**Privacy**: no telemetry. Update checks contact GitHub, npm and other official sources only; set `SKILL_MANAGER_UPDATES_OFFLINE=1` to turn them off.
