# Skill Control v0.3.1

Skill Control 是一个本地优先的 AI Agent 管理工具：在一处查看和整理 Codex、Claude Code、WorkBuddy、Hermes、OpenClaw 等 Agent 的技能、插件、MCP、命令行工具和用量。这一版加了“暂停此技能”：让 Agent 暂时用不了某个技能，随时可以恢复。v0.3.0 的“技能库优先”等改动也一起成为正式版。

[English below](#english)

## 主要变化

- **暂停此技能**：在技能详情的“技能库”一栏点“暂停此技能”。确认窗口会列出每个 Agent 怎么关：
  - Codex、Gemini、OpenClaw、QClaw、办公小浣熊、Hermes：写它们自己的停用开关。
  - Claude Code、WorkBuddy 等逐个建链接的 Agent：取下链接。它们自己目录里有同名副本的，先把那份移到 Skill Control 的数据目录里。
  - Cursor 这类直接读取技能库、又没有停用开关的 Agent：暂停不到，会单独标出来。
- **恢复此技能**：暂停后，详情里会显示从哪天起暂停、哪些 Agent 用不了，点“恢复此技能”按记录改回来。配置文件按现在的内容只去掉当时加的那一项，不会用旧备份整份覆盖，这期间 Agent 自己改过的设置都会保留。
- 暂停期间，自动接入和“补齐接入”不会把这个技能接回去；技能列表里会标“已暂停”。
- 命令行新增 `skill-control pause <名称>` 和 `skill-control resume <名称>`，`status` 也会显示暂停状态；随附的 skill-control 技能会先预览再暂停。
- 每次暂停和恢复都会先备份，也能在操作历史里撤销。

如果你还在用 0.2.x，这一版同时带来 v0.3.0 的全部改动：技能库优先、自动接入、命令行工具、新的首次使用引导、“自动检查更新”开关和固定证书签名，详见 [v0.3.0 发布说明](https://github.com/zifeixu85/skill-control/releases/tag/v0.3.0)。

## 第一次打开

- **macOS**：把应用拖进“应用程序”后双击打开。提示 未打开“Skill Control” 时点“完成”，再到“系统设置 → 隐私与安全性”底部点“仍要打开”，并用密码或触控 ID 确认。这个按钮只在被拦后大约一小时内显示，找不到就先再双击一次应用。详细步骤和签名核对方法见 [README](https://github.com/zifeixu85/skill-control#首次打开macos)。
- **从 0.2.x 升级的 Mac**：从 v0.3.0 起改用固定证书签名，这次更新时 macOS 可能会再要一次“App管理”授权，按提示允许即可；以后的更新会保留这个授权。
- **Windows**：SmartScreen 提示“Windows 已保护你的电脑”时，点“更多信息 → 仍要运行”。
- **Linux**：AppImage 需要先赋予执行权限（`chmod +x`），并装好 libfuse2。

## 隐私

没有遥测，不上传技能、对话、密钥或路径。暂停记录只保存在本机的 `~/.agent-skill-manager/paused-skills.json`。检查更新会访问 GitHub、npm 和各 Agent 应用自己的更新地址，可以在“设置 → 数据与隐私”里关闭。详见[隐私说明](https://github.com/zifeixu85/skill-control/blob/main/PRIVACY.md)。

## 已知限制

- 界面目前只有简体中文。
- 直接读取技能库、又没有已核实停用开关的 Agent（Cursor、GitHub Copilot、OpenCode、Windsurf、Amp）暂停不到；WorkBuddy 和 Trae 自己的停用开关还没有接入，暂停时用取下链接代替。
- macOS 版没有经过 Apple 公证，第一次打开需要在“隐私与安全性”里放行。
- Windows 和 Linux 版测试较少；命令行工具 `skill-control` 目前只支持 macOS 和 Linux。

完整变化见 [CHANGELOG](https://github.com/zifeixu85/skill-control/blob/main/CHANGELOG.md)。

## English

Skill Control is a local-first manager for AI coding agents: see and organize the skills, plugins, MCP servers, command-line tools and usage of Codex, Claude Code, WorkBuddy, Hermes, OpenClaw and more in one place. This release adds pausing a skill, so agents can't use it for a while until you resume it. It also makes the v0.3.0 changes (library first and more) a regular release.

> **The app's interface is currently Simplified Chinese only.**

**What's new**

- **Pause a skill** (暂停此技能, in the 技能库 part of a skill's details): the confirmation lists how each agent is switched off. Codex, Gemini, OpenClaw, QClaw, Office Raccoon and Hermes get their own disable switch; Claude Code, WorkBuddy and other link-based agents lose their link, and their own copy with the same name is moved into Skill Control's data folder. Agents that read the library themselves and have no switch, such as Cursor, can't be paused and are listed separately.
- **Resume** (恢复此技能): the details show since when the skill is paused and which agents can't use it. Resuming turns back exactly what the pause changed, editing each config as it is now (only the entry the pause added is removed), so settings the agent changed in the meantime are kept.
- While a skill is paused, auto-link and catch-up leave it alone, and the skills list marks it as paused.
- New commands `skill-control pause <name>` and `skill-control resume <name>`; `status` shows the pause; the bundled skill-control skill previews a pause before running it.
- Every pause and resume is backed up first and can be undone from the history.

Coming from 0.2.x, you also get everything in v0.3.0: library first, auto-link, the command line, the new onboarding, the automatic update checks switch and the fixed signing certificate. See the [v0.3.0 notes](https://github.com/zifeixu85/skill-control/releases/tag/v0.3.0).

The `.zip`, `latest*.yml` and `.blockmap` files are for in-app updates; you don't need them. `SHA256SUMS.txt` lists checksums for every file.

**First launch**: on macOS, click Done when it says "Skill Control" Not Opened, then click Open Anyway at the bottom of System Settings → Privacy & Security and confirm with your password or Touch ID. The button only shows for about an hour after the app was blocked; if it's missing, double-click the app again first. Details and how to check the signature are in the [README](https://github.com/zifeixu85/skill-control/blob/main/README_EN.md#first-launch-on-macos). On Windows, choose More info → Run anyway in SmartScreen. On Linux, `chmod +x` the AppImage and install libfuse2.

**Upgrading a Mac from 0.2.x**: from v0.3.0 the app is signed with a fixed certificate, so this one update may ask for App Management permission again; allow it when prompted. Later updates keep the permission.

**Privacy**: no telemetry; skills, conversations, secrets and paths are never uploaded. Pause records stay on your computer in `~/.agent-skill-manager/paused-skills.json`. Update checks contact GitHub, npm and each agent app's own update address, and can be turned off in 设置 → 数据与隐私 (Settings → Data and privacy). See the [privacy notice](https://github.com/zifeixu85/skill-control/blob/main/PRIVACY.md#english).

**Known limitations**

- The interface is Simplified Chinese only.
- Agents that read the library themselves and have no verified switch (Cursor, GitHub Copilot, OpenCode, Windsurf, Amp) can't be paused; WorkBuddy's and Trae's own switches are not supported yet, so pausing removes their link instead.
- The macOS app is not notarized by Apple, so the first launch has to be allowed in Privacy & Security.
- The Windows and Linux builds are less tested; the `skill-control` command line supports macOS and Linux only.
